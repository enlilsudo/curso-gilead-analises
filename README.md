# Curso Gilead — Análises (Identidade Azul Celeste)

Site estático pronto para GitHub Pages, sem dependências externas. Identidade visual com azul celeste como base e uma cor própria para cada serviço: violeta para Astrologia Qabbalística, verde para Guematria, coral para Enneagrama e azul para o Calendário Luni-Solar.

## Serviços
- Astrologia Qabbalística: formulário e roteiro inicial; não calcula posições planetárias exatas.
- Guematria de nomes: calculadora hebraica no sistema padrão e opção de redução.
- Enneagrama: questionário informal de autoconhecimento, não diagnóstico.
- Calendário Luni-Solar Hebreu: projeção didática personalizada ancorada em 16/10/2026 = 6 de Cheshvan de 5787; usa meses alternados de 30 e 29 dias (média de 29,5), início do dia ao pôr do sol como convenção descritiva e Adar como nome único.

## Publicar
1. Crie um repositório público no GitHub.
2. Envie `index.html` e `README.md` para a raiz.
3. Vá a Settings → Pages.
4. Selecione Deploy from a branch, branch `main`, pasta `/(root)` e salve.
5. Aguarde o GitHub Pages publicar o endereço.

## Limitações
O site não calcula efemérides, ascendente ou casas; o calendário é uma projeção personalizada ancorada na data informada pelo usuário, não uma conversão oficial nem previsão astronômica real; o questionário não é teste validado. Não coleta nem envia os dados inseridos a um servidor.
